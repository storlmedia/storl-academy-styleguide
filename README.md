# Storl-Academy Styleguide

The binding reference for colors, fonts, spacing and components on
storl-akademie.de.

## Ground rules

- The styleguide is the target, not a description of the site today. Where the
  live site disagrees, the site gets adjusted.
- Token names are the reference, not hex codes or pixel values. Gutenberg's and
  Elementor's global colors and fonts are named after them.
- The published page is German because its readers are. Token names and this
  README are English.

## Publishing

GitHub Pages serves the `docs/` folder on the default branch. No build step —
pushing publishes.
